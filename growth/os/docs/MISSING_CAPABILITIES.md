# MISSING_CAPABILITIES — thiếu gì, ai lo, chặn gì

| Thiếu | Chặn | Ai | Cần Founder? |
|---|---|---|---|
| App trên Google Play / App Store (chưa có build native) | Install thật theo định nghĩa store | Founder + code | **Có** — ngày dự kiến build |
| Đổi tên/bundle trong `app.json` (còn `DailyOps`) | Lên store | code (approval code_change) | Có |
| Tên miền chốt | Canonical, GA4, Search Console, deploy | Founder | **Có** |
| Deploy blog công khai (chưa có pipeline/hosting ghi trong repo) | Mọi kênh organic | seo-content + Founder | Có (hosting) |
| GA4 property + event `cta_click`, `appinstalled` | Đo pageview/waitlist/PWA install | growth-analytics | Có (tạo tài khoản) |
| Form waitlist + ESP | Chỉ số dẫn đường, newsletter | seo-content | Có (chọn ESP) |
| Widget máy tính (10 cái mô tả, 0 build) | CTA mạnh nhất, demo sản phẩm | seo-content/creative (code web, không đụng app) | Không, nhưng cần duyệt nơi đặt (growth/site) |
| Ảnh bài blog | Publish đẹp | tools/admin + GEMINI_API_KEY | Có (key) |
| Tài khoản social Mira (FB Page, Threads, TikTok, YouTube) | Đăng organic | Founder tạo; hệ thống soạn | **Có** |
| Tài khoản Meta Ads / Google Ads + pixel | Paid test | Founder | Có (chỉ Phase 3) |
| Search Console | SEO impressions | Founder xác minh domain | Có |
| Pipeline deploy / CI | Tự động hoá publish | — | Có (chọn hosting) |
| Brand tokens/logo | Creative nhất quán | creative-studio | Không |
| Danh sách cộng đồng/đối tác | Distribution | community-partnerships | Không |
| Footage app thật | Video | creative-studio (cần app chạy trên điện thoại) | Không |
| Analytics trong app (first_open, retention) | Funnel sau install | **Không làm ở V1** (ràng buộc #5) | Có nếu muốn đổi |
